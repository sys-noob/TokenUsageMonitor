# Token Usage Monitor - 设计文档

> 界面视觉设计规格，涵盖配色方案、布局尺寸、动画参数及组件样式。
> **设计原则**：保持莫兰迪低饱和配色，功能布局参考 `reference/coding-quota-bar.gif`。

---

## 1. 设计原则

- **低饱和优先**: 所有颜色取自莫兰迪色系，避免纯黑、纯白、高饱和色
- **微质感扁平**: 卡片有轻微层级区分（背景色差异），无强烈拟物阴影
- **信息密度适中**: 一屏展示核心信息，不堆砌
- **动画克制**: 仅使用淡入淡出和宽度过渡，不过度炫技

## 4. 弹窗布局规格

```
窗口尺寸: 320px (宽) × 420px (高)
内边距: 16px（左右），12px（上下）
背景色: #E8E3DF
圆角: 12px
阴影: Opacity 0.15, Blur 16px, Y偏移 4px
```

### 4.1 标题栏

- **高度**: 44px
- **背景**: 透明（与窗口背景融合）
- **左侧**: 应用标题 "Coding Plan 用量监控"，16px SemiBold，`#4A4A4A`
- **右侧**: 图标按钮组，间距 8px
  - 通知图标（铃铛）
  - 夜间模式切换（月亮）
  - 设置（齿轮）
  - 刷新（循环箭头）

### 4.2 平台 Tab 切换器

- **位置**: 标题栏下方
- **样式**: 横向排列的 ToggleButton / RadioButton 组
- **尺寸**: 每个 Tab 宽 ~80px，高 32px
- **未选中状态**: 背景透明，文字 `#9B9B9B`，12px Regular
- **选中状态**: 背景 `#F5F0EB`，文字 `#4A4A4A`，12px SemiBold，圆角 16px（胶囊形）
- **间距**: Tab 之间 4px

## 5. 各平台内容规格

### 5.1 GLM 页面

- **大用量卡片**: "MCP 用量" + 百分比 + 横向进度条 + 日期
- **两个小额度卡片**: "5小时额度"、"周额度"，各占 ~48% 宽度，并排
- **Token/MCP 切换标签**: 横向两个选项
- **时间维度**: 本日 / 24h / 7天 / 30天
- **使用统计**: 总用量文字 + 堆叠柱状图
- **系统健康度**: 折线图（可选）

### 5.2 KIMI 页面

纵向列表，每个模型一个卡片行：
- **模型名**: 14px SemiBold，`#4A4A4A`
- **时间范围**: 12px Regular，`#9B9B9B`
- **用量/总额**: 12px Regular，`#9B9B9B`
- **百分比**: 14px Bold，`#4A4A4A`，右侧对齐
- **进度条**: 横向，高 4px，品牌色填充

模型列表示例：KIMI-M*、speech-hd、KIMI-Hailuo 等

### 5.3 DeepSeek 页面

- **余额卡片**: "总余额 ¥50.00"，大字体，包含赠送余额/充值余额细分
- **进度条**: 展示余额消耗比例
- **服务状态列表**: 
  - 服务名称 + 运行状态（绿点 + "运行正常"）
  - 百分比（99.86%）
  - 小方块矩阵：绿色方块表示正常，红色表示异常

## 7. Tab / 标签 / 切换器样式

### 7.1 Token / MCP 切换

- **样式**: 横向两个 ToggleButton
- **未选中**: 背景透明，文字 `#9B9B9B`，12px Regular
- **选中**: 背景 `#4A4A4A`，文字 `#FFFFFF`，12px SemiBold，圆角 4px
- **尺寸**: 宽 ~48px，高 24px

### 7.2 时间维度切换

- **样式**: 横向四个 ToggleButton（本日 / 24h / 7天 / 30天）
- **未选中**: 背景透明，文字 `#9B9B9B`，11px Regular
- **选中**: 背景 `#F5F0EB`，文字 `#4A4A4A`，11px SemiBold，圆角 12px（胶囊形）
- **尺寸**: 宽 ~40px，高 22px

## 8. 图表组件规格

### 8.1 堆叠柱状图

- **容器高度**: ~100px
- **柱宽**: 自适应，柱间距 2px
- **柱形**: 底部圆角 2px，顶部无圆角
- **系列色**: 使用「图表系列色」表格中的颜色
- **Y轴**: 不显示刻度线，仅显示最大/中间值标签
- **X轴**: 时间标签，10px，`#9B9B9B`，倾斜或省略避免重叠
- **Tooltip**: 黑色半透明背景，圆角 4px，文字 `#FFFFFF`，11px

### 8.2 折线图（系统健康度）

- **容器高度**: ~80px
- **线条**: 宽 2px，使用折线系列色
- **数据点**: 不显示（或仅 Hover 显示）
- **Y轴**: 范围 0~100，显示刻度标签
- **X轴**: 日期标签
- **区域填充**: 线条下方可填充半透明渐变色

## 9. 动画参数

| 动画 | 时长 | 缓动函数 | 说明 |
|------|------|----------|------|
| 弹窗淡入 | 150ms | CubicEase Out | Opacity 0→1 + TranslateY 8px→0 |
| 弹窗淡出 | 120ms | CubicEase In | Opacity 1→0 |
| 进度条宽度 | 300ms | CubicEase Out | Width百分比变化时平滑过渡 |
| 按钮按下 | 80ms | Linear | Scale 1→0.97，松开后恢复 |
| Loading旋转 | 800ms | Linear | 无限循环旋转 |
| 数据刷新脉冲 | 200ms | CubicEase | 卡片背景色短暂高亮后恢复 |
| Tab 切换内容 | 150ms | CubicEase Out | 内容区 Opacity 交叉淡入淡出 |

## 11. 按钮样式

### 11.1 图标按钮（标题栏）

- **尺寸**: 28×28px
- **背景**: Transparent
- **图标颜色**: `#9B9B9B`
- **Hover**: 背景 `#D5CEC7` + 图标 `#4A4A4A`
- **圆角**: 50%（圆形）

### 11.2 切换标签按钮

- **尺寸**: 根据内容自适应，高 22~24px
- **未选中**: 背景透明，文字 `#9B9B9B`
- **选中**: 背景 `#F5F0EB` 或 `#4A4A4A`，文字 `#4A4A4A` 或 `#FFFFFF`
- **圆角**: 4px ~ 12px（根据类型）

---

## 12. 托盘图标规格

- **尺寸**: 16×16px (系统托盘标准)
- **正常状态**: 彩色图标（主色调 `#B5A89A`）
- **异常状态**: 图标变为灰粉色 `#C8A8A0` 或带小红点角标
- **格式**: ICO（多分辨率 16/24/32/48px）
