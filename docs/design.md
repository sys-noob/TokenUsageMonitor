# Token Usage Monitor - 设计文档

> 界面视觉设计规格，涵盖配色方案、布局尺寸、动画参数及组件样式。

---

## 1. 设计原则

- **低饱和优先**: 所有颜色取自莫兰迪色系，避免纯黑、纯白、高饱和色
- **微质感扁平**: 卡片有轻微层级区分（背景色差异），无强烈拟物阴影
- **信息密度适中**: 一屏展示核心信息，不堆砌
- **动画克制**: 仅使用淡入淡出和宽度过渡，不过度炫技

## 4. 平台卡片组件规格

- **尺寸**: 宽度100%（280px），高度自适应（约80-90px）
- **背景**: `#F5F0EB`
- **圆角**: 8px
- **内边距**: 16px
- **左侧色条**: 宽4px，高100%，圆角2px，平台品牌色
- **平台Logo**: 24×24px 色块或字母缩写，品牌色背景 + 白色文字
- **平台名**: 14px, SemiBold, `#4A4A4A`
- **已用/总额**: 12px, Regular, `#9B9B9B`
- **百分比**: 14px, Bold, 品牌色（右侧对齐）
- **进度条**: 高6px，圆角3px，背景 `#D5CEC7`，填充品牌色

## 5. 动画参数

| 动画 | 时长 | 缓动函数 | 说明 |
|------|------|----------|------|
| 弹窗淡入 | 150ms | CubicEase Out | Opacity 0→1 + TranslateY 8px→0 |
| 弹窗淡出 | 120ms | CubicEase In | Opacity 1→0 |
| 进度条宽度 | 300ms | CubicEase Out | Width百分比变化时平滑过渡 |
| 按钮按下 | 80ms | Linear | Scale 1→0.97，松开后恢复 |
| Loading旋转 | 800ms | Linear | 无限循环旋转 |
| 数据刷新脉冲 | 200ms | CubicEase | 卡片背景色短暂高亮后恢复 |

## 7. 按钮样式

### 主按钮（并发测试）
- 背景: `#B5A89A`
- 文字: `#FFFFFF`
- 圆角: 6px
- 高: 36px
- Hover: 背景加深至 `#A89888`
- Pressed: Scale 0.97

### 图标按钮（刷新、关闭）
- 尺寸: 28×28px
- 背景: Transparent
- 图标颜色: `#9B9B9B`
- Hover: 背景 `#D5CEC7` + 图标 `#4A4A4A`
- 圆角: 50%（圆形）

---

## 8. 托盘图标规格

- 尺寸: 16×16px (系统托盘标准)
- 正常状态: 彩色图标（主色调 `#B5A89A`）
- 异常状态: 图标变为灰粉色 `#C8A8A0` 或带小红点角标
- 格式: ICO（多分辨率 16/24/32/48px）
