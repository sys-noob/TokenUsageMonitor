# Token Usage Monitor - 设计文档

> 界面视觉设计规格。 **设计原则**：遵循 Windows 11 原生设计风格，使用系统主题色，自动适应浅色/深色模式。

---

## 1. 设计原则

- **原生优先**: 使用 Windows 系统颜色（`SystemColors` / `AccentColor`），不自定义色板
- **跟随系统**: 默认跟随 Windows 浅色/深色设置，也允许手动切换
- **信息密度适中**: 一屏展示核心信息，不堆砌
- **动画克制**: 仅使用淡入淡出和宽度过渡

---

## 2. 颜色来源

所有颜色从 Windows 系统主题获取，不硬编码色值：

| 用途 | 来源 | 说明 |
|------|------|------|
| 主背景 | `SystemColors.WindowBrush` | 跟随系统浅色/深色 |
| 卡片/次级背景 | `SystemColors.ControlLightBrush` | 层级区分 |
| 主文字 | `SystemColors.WindowTextBrush` | 高对比度 |
| 次要文字 | `SystemColors.GrayTextBrush` | 低对比度 |
| 进度条填充 | `SystemColors.HighlightBrush` | 系统强调色 |
| 进度条背景 | `SystemColors.ControlBrush` | 浅灰底 |
| 成功/正常 | `#10893E` (Win11 green) | 固定色值 |
| 错误 | `#C42B1C` (Win11 red) | 固定色值 |

**平台品牌色**（三平台卡片区分用，不依赖莫兰迪）：

| 平台 | 色值 | 说明 |
|------|------|------|
| GLM | 系统强调色变体 | 可在设置中自定义 |
| KIMI | 系统强调色变体 | |
| DeepSeek | 系统强调色变体 | |

```
┌──────────────────────────────────────────┐
│  Token 用量监控          ⟳ ⚙ ☾ ✕  │  ← 标题栏
├──────────────────────────────────────────┤
```

## 4. 弹窗布局规格

```
窗口尺寸: 320px (宽) × 420px (高)
圆角: 8px (Windows 11 默认圆角)
背景: 系统 WindowBrush
```

### 4.1 标题栏

- **左侧**: "Token 用量监控"，Segoe UI 14px SemiBold
- **右侧**: 图标按钮组（刷新/设置/夜间模式/关闭），Segoe MDL2 Assets

### 4.2 平台 Tab 切换器

- 横向排列 ToggleButton，胶囊形（CornerRadius=16）
- 未选中: 透明背景 + 次要文字色
- 选中: 卡片背景 + 主文字色 + SemiBold
